# Risk review

Run an Open Risk Review of this repository.

Read `.open-risk-review/SKILL.md` and follow it step by step, using
`.open-risk-review/CHECKLIST.md` for the controls and
`.open-risk-review/TEMPLATE.md` for the report. Run the four review passes
one after another. Stay read-only: the only file you write is the report in
`.risk-review/`, plus the one `.gitignore` line the method offers, and only if
the user says yes.
